# Documents

## The Start
Welcome this is the organizing section of all notes taken in my Obsidian Vault. The goal of this directory is to give me remote access to these notes without the need of utilizing the Obsidian sync feature. Reason for this is because I will like to choice free options; nothing more than that. Have a great time!

### Overview
* `main`: The default location for all markdown files.
* `documents`: Location including all pdf and epub files. Locate notes  that are created in association with a specific pdf or epub.
* `projects`: Location including all markdown notes that cover a specific project. These projects notes include ideas, plans, and frameworks.
* `questions`: Location including all markdown notes that cover queries for future reference.
* `systems`: Location including all digital mindmaps (`.canvas`).
* `web-clips`: Location including all markdown notes that cover videos and any form of online information. Normally associated with the obsidian web-clipper plugin for Brave-Browser
