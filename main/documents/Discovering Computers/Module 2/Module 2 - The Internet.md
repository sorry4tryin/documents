## Objective 1 - Evolution of the Internet

### The Internet vs. The Web
- The **Internet** is a global system of networks connecting billions of users to services
- The **web** is one service on the Internet (alongside email, file transfer, messaging)
- The web emerged in the early 1990s as an easier way to access online information using a browser

### Key History
- Developed in the late 1960s (ARPANET)
- Both public and private organizations own networks on the Internet
- Phone companies, cable/satellite companies, and the government contribute to its infrastructure

### Net Neutrality
- The concept that one website has the same value/priority as other websites
- Equal, unrestricted access to each site
- When enforced, ISPs must provide the same level of service to all websites regardless of content or purpose
- **Supporters argue:** access cannot be restricted based on content or bandwidth requirements
- **Opponents argue:** high-bandwidth content (streaming music/movies) could slow Internet speeds for others; ISPs could charge more for resource-heavy content

### Who Controls the Internet?
- No single person, company, or government owns it
- **FCC** (U.S. Federal Communications Commission) - rules surrounding Internet access
- **IETF** (Internet Engineering Task Force) - sets standards for devices/services/applications to work together
- **W3C** (World Wide Web Consortium) - writes web standards; supports net neutrality, accessibility, and security

### Bandwidth
- **Bandwidth** = capacity of a communications channel
- **High-bandwidth (broadband):** supports videos, music, large files, online gaming
- **Low-bandwidth (narrowband):** suitable for email, small files, basic websites

## Objective 2 - How to Use the Web

### Web Basics
- A **webpage** is a specially formatted document with text, graphics, sound, video, and links
- **Hyperlinks (links):** words or graphics you click to display a webpage or resource
- **Static webpage:** same content each time
- **Dynamic webpage:** content regenerated each visit (customized content like weather, stock quotes)
- A **website** = collection of related webpages + documents/photos stored on a web server
- A **web server** is a computer that delivers requested webpages

### Webpage Structure
- Header/banner, navigation bar/menu, body, sidebar, footer
- Each area can include text, graphics, links, and media

### Responsive Web Design (RWD)
- Adapts layout to fit the screen on which it is displayed
- **HTML** (Hypertext Markup Language) - specifies layout (headings, paragraphs, images, links)
- **CSS** (Cascading Style Sheets) - specifies design and appearance

### Browsers
| Browser             | Key Features                                                             |
| ------------------- | ------------------------------------------------------------------------ |
| **Apple Safari**    | Default for macOS since 2003; built-in social sharing, parental controls |
| **Google Chrome**   | Free, independent tabbed browsing (one tab crash doesn't affect others)  |
| **Microsoft Edge**  | Default Windows browser; Cortana/OneDrive integration, annotation        |
| **Mozilla Firefox** | Extensive plug-ins, enhanced privacy/security, password manager          |

### Browser Features
- **Cache:** holding area storing copies of pages you view (loads faster next time)
- **Cookies:** small text files generated by web servers to store info (items viewed/purchased)
- **Breadcrumbs:** path you followed to display a webpage
- **Favorites/Bookmarks:** preferred websites saved for quick access

### URLs and Addresses
- **URL (Uniform Resource Locator):** address identifying a page's location on the Internet
- **IP Address:** unique number (e.g., 69.32.132.255) - identifies every computer on the Internet
  - **IPv4:** four sets of numbers 0-255 separated by periods
  - **IPv6:** increased available IP addresses exponentially
- **TCP/IP:** set of protocols used by all Internet computers (TCP routes data, IP assigns unique addresses)
- **Domain name:** portion of URL identifying IP addresses (e.g., cengage.com)
- **Top-level domain (TLD):** three-letter extension indicating organization type
  - .com = commercial, .edu = educational, .gov = government, .org = nonprofit, .net = network providers

### How Data Travels
- **Internet backbone:** major carriers of network traffic across the U.S.
- **DNS (Domain Name System):** translates domain names to IP addresses
- **DNS server:** associated with an ISP, routes requests to correct computer

## Objective 3 - Techniques for Connecting to the Internet

### Connection Types
- **Wired:** physical cable/wire to a modem
- **Wireless:** wireless modem using cellular radio, satellite, or Wi-Fi
- Most connections are **broadband** (always-on, high capacity)

### Selecting an ISP
Consider:
- **Activities:** what types of tasks (affects bandwidth needs)
  - Megabyte (MB) ≈ 1 million characters
  - Gigabyte (GB) ≈ 1 billion characters
- **Number of devices:** may vary by day/season
- **Travel access:** reliable service where you travel
- **Budget:** find best value for your needs

### Cellular Networks
- **4G** (fourth generation): Internet services in most cellular locations
- **5G:** higher-speed data transmission, better for high-bandwidth content
- Home users increasingly use cellular for Internet instead of wired

### Wi-Fi and Hot Spots
- **Wi-Fi hot spots:** wireless networks in public places (hotels, restaurants, coffee shops)
- Some require agreeing to terms of service or obtaining a password
- **Mobile hot spot:** smartphone or separate device creating a wireless network via cellular
  - May have extra fees; data counts toward usage
  - Typically not as fast as Wi-Fi networks

### Connecting to a Wireless Network
1. Identify the network by its **SSID** (Service Set Identifier)
2. Select the network name
3. Connect (tap/click appropriate button)
4. Enter **wireless network key** if required (secure network)
5. Some public networks require browser agreement to terms of service
6. Turn off devices when not in use for extended periods

### Wireless Access Point (WAP)
- Allows Wi-Fi compliant devices to connect to a network
- Hotels and airports often provide free wireless Internet

## Objective 4 - Online Activities and Services

### Website Categories
| Category                    | Purpose                                                           |
| --------------------------- | ----------------------------------------------------------------- |
| **Informational/Research**  | Factual info (libraries, encyclopedias, dictionaries)             |
| **News/Weather/Sports**     | Current events, customizable local news, alerts                   |
| **Bookmarking**             | Organize, tag, share links (e.g., Pinterest)                      |
| **Educational**             | Formal/informal teaching, tutorials, online classes               |
| **Business/Government/Org** | Brand awareness, company info, government services                |
| **Blogs**                   | Time-stamped articles in diary format (vlogs = video blogs)       |
| **Wikis**                   | Collaborative websites for editing/sharing info (e.g., Wikipedia) |
| **Health/Fitness**          | Medical, fitness, nutrition information                           |
| **Science**                 | Space, astronomy, physics, earth sciences                         |
| **Entertainment**           | Music, videos, games, streaming media                             |
| **Travel/Tourism**          | Research travel, book flights/hotels                              |
| **Mapping**                 | Search addresses, get directions, GPS integration                 |
| **Banking/Finance**         | Online banking, trading, bill pay                                 |
| **Retail/Auctions**         | E-commerce storefronts, online auctions (e.g., eBay)              |
| **Careers/Employment**      | Job search, salary data, training requirements                    |
| **Portals**                 | Combine pages from many sources, customized                       |
| **Content Aggregation**     | Gather and distribute web content (e.g., Flipboard)               |

### Web Apps
- Apps you run entirely in a browser (reside on server, not your device)
- Examples: Microsoft Office web apps, Google Docs, Slack, Trello, Box, Skype

**Pros:** access from any device, collaborate remotely, save storage, auto-updates
**Cons:** must be online, vulnerable to security issues, may lose files if provider fails, fewer features

### E-commerce
- Business transactions over electronic networks
- **B2C** (Business-to-Consumer): goods/services to general public
- **C2C** (Consumer-to-Consumer): one consumer sells to another (e.g., eBay)
- **B2B** (Business-to-Business): businesses providing goods/services to other businesses

### Online Communication Tools
- **Email:** messages/files via computer network; uses email addresses (username@domain)
- **Messaging Apps:** real-time text, chat, multimedia, voice messaging, voice-to-text
- **Podcasts:** recorded media for download/streaming (audio or video)
- **Web Conferencing (Videoconference):** meetings among geographically separated people
  - Features: whiteboard, file sharing, chat, automatic translation, captioning
  - **Webinar:** web-based seminar with shared screen + audio/video
- **VoIP (Voice over Internet Protocol):** voice communications over Internet (e.g., Skype)
- **FTP (File Transfer Protocol):** upload/download files between local computer and remote server

## Objective 5 - Staying Safe Online

### Secure Websites
- Use **encryption** to safeguard transmitted information (scrambles data)
- Display **https** (Hypertext Transfer Protocol Secure) instead of http
- Use **digital certificates** to verify identity with a digital key signed by trusted third party

### Online Safety Tips
1. **Verify the website is safe** - type addresses directly; don't click email links; check for https and closed padlock
2. **Turn off location sharing** - can be misused by dishonest individuals
3. **Clear browsing history** - cache may contain passwords and account numbers
4. **Never store passwords** - anyone accessing your computer can view them
5. **Use a phishing filter** - warns/blocks fraudulent or suspicious websites
6. **Enable pop-up/pop-under blocker** - stops malicious advertisements
7. **Use private browsing** - discards passwords, temporary files, form data when you exit
8. **Use a proxy server** - screens incoming/outgoing messages to protect online identity

### Secure E-commerce Payments
- Verify website security before providing credit card numbers
- **3D Secure:** protocol using encryption + digital certificates for extra security
- **TLS (Transport Layer Security):** encrypts data for e-commerce
- **Online payment services:** PayPal, Square Cash, Venmo, Zelle (adds protection layer)
- **Mobile payments:** Apple Pay, Google Wallet (scan phone over reader)
- **Virtual account numbers:** one-time numbers that are worthless if stolen

## Objective 6 - Social Networks

### What Are Social Networks?
- Websites encouraging members to share interests, ideas, stories, photos, music, videos
- Popular: Facebook, Twitter, Instagram, Snapchat, LinkedIn
- Include profile info (name, location, photos, interests)
- Can designate friends/contacts; some require confirmation (Facebook, LinkedIn), others don't (Twitter)

### Types of Social Media
| Type | Examples |
|------|----------|
| **Social networking** | Facebook, LinkedIn, Instagram, Snapchat |
| **Blogging/microblogging** | Twitter, Blogger, WordPress, Tumblr, Pinterest |
| **Media/content sharing** | YouTube, Flickr, Photobucket |
| **Collaborative projects** | Wikipedia, WikiAnswers |
| **Social curation/bookmarking** | Delicious, Reddit, Digg |
| **File sharing** | Dropbox, WeTransfer, Egnyte |
| **Virtual social worlds** | World of Warcraft, Xbox, Steam |
| **Crowdfunding** | GoFundMe, Kickstarter, Indiegogo |

### Business Uses
- Learn about customers through feedback/comments
- Advertise products, services, events
- Nonprofits promote activities, accept donations, connect with volunteers
- Blogs for employee/customer/vendor communication

### Personal Uses
- Share photos, videos, greetings, status updates
- "Like" content on Facebook/Google+
- News feed shows activity updates from friends

### Privacy and Security Risks
1. **Register with caution** - provide only necessary info; don't disclose birthdate, birthplace
2. **Manage your profile** - check privacy settings regularly
3. **Choose friends carefully** - watch for fake profiles from identity thieves
4. **Limit friends** - functional network shouldn't exceed ~150 people
5. **Divulge only relevant information** - anything posted may be public permanently
6. **Be leery of urgent requests** - don't respond to emergency pleas or too-good-to-be-true deals
7. **Read the privacy policy** - understand how your info is used

### Types of Social Networks
- **Media sharing sites** (YouTube, Flickr) - post, organize, store, download media
- **Photo sharing** (Instagram, Flickr) - post photos, organize into albums, add tags
- **Discussion forums** (Quora) - online conversations on any topic
- **Video sharing** (YouTube, Vimeo) - post clips for public or invited viewers
- **Consumer review networks** (TripAdvisor, Yelp, Angi) - ratings and reviews

## Objective 7 - Conduct and Evaluate Online Searches

### Information Literacy
- The ability to find, evaluate, use, and communicate online information
- Navigate many sources, select the right tool, recognize unreliable info, evaluate for bias

### How Search Engines Work
- Don't search the entire Internet - compile a database using **spiders/crawlers**
- Build an **index** of terms and their locations
- **Query** = search term entered to obtain results
- Ranking based on: frequency/location of term, how long published, number of inbound links

### Search Strategy
1. State what information you need (as specifically as possible)
2. Phrase the search as a question
3. Identify keywords or phrases
4. Select an appropriate search tool

### Refining Searches
- Too general → millions of results → narrow with specific keywords
- Too specific → miss useful pages → broaden by removing keywords
- **Word stems:** base of a word (e.g., "business" instead of "businesses")
- **Wildcards:** `*` placeholder (e.g., `tech*` finds technology, technician, technique)

### Search/Boolean Operators
| Operator | Meaning | Example |
|----------|---------|---------|
| `" "` | Exact phrase | `"augmented reality"` |
| `\|` | OR | `augmented \| virtual` |
| `-` | NOT | `augmented reality -virtual` |
| `*` | Wildcard | `augment* reality` |
| `#..#` | Number range | `augmented reality 2017..2022` |

### Search Tools
- **General search engines** (Google) - broad results
- **Web/subject directories** - curated by human editors, better for research
- **Specialized search tools** (Google Scholar, Congress.gov) - focused on specific resources

### Evaluating Website Content (CARS Checklist)
- **Credibility:** identify author, check credentials, search LinkedIn/Google
- **Accuracy:** verify facts (snopes.com, factcheck.org), check URL legitimacy, check publish date
- **Reasonableness:** identify purpose, check for multiple viewpoints, watch for emotional language, conflicts of interest
- **Support:** look for citations, links to reputable sources, expert quotations, credit lines

## Objective 8 - Considerations for Using Online Content

### Using Content Ethically
- Respect **intellectual property rights** - need permission for copyrighted material
- **Copyright** = legal right to control original work (applies automatically)
- **Public domain** = free to use without permission
- **Creative Commons (CC)** = licenses letting creators share under specific conditions
- **DRM (Digital Rights Management)** = prevents unauthorized copying
- **Fair use** = limited use allowed with citation
- **Plagiarism** = using someone's work without citation (even paraphrasing requires citation)

### Gathering Content
- Follow ethical guidelines to avoid legal/academic/professional sanctions
- Get permission before using photos/content from the Internet
- Contact the owner, explain usage, keep records of permission
- U.S. government sites often public domain (but attribute and check for other copyrighted info)
