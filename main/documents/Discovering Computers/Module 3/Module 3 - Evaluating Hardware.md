## Objective 1 - Considerations When Purchasing Technology Devices

### Define Each Component of Computer Hardware
- **Hardware** = physical components that allow a device to operate (wires, cases, switches, electronic circuits)
- **CPU (Central Processing Unit)** = complex integrated circuit responsible for converting input (data) into output (information)
  - Data travels in/out through embedded wires called a **bus**
  - **Processor core** = unit on the processor with circuitry to execute instructions
  - **Multi-core processor** = processor with multiple cores (perform better, more expensive)
  - **Processor cache** = stores frequently used data next to processor for quick retrieval
- **Control unit** = manages flow of instructions within the processor
- **ALU (Arithmetic Logic Unit)** = performs arithmetic operations in the CPU

### Computer Memory
- **RAM (Random Access Memory)** = temporarily stores running apps and document data while computer is on
  - Stored on chips connected to the motherboard
  - **Volatile** = loses contents when power is removed
  - Types: DRAM, SRAM, MRAM, Flash memory
- **ROM (Read-Only Memory)** = permanently installed on motherboard
  - Contains **BIOS** (basic input/output system) - tells computer how to start
  - Performs **POST** (power-on self test) at startup
  - **Nonvolatile** = does not lose contents when power is removed
  - **Firmware** = updated instructions on ROM chip
- **Virtual memory** = OS capability to temporarily store data on storage medium when RAM is full
  - **Swap file/paging file** = area of hard drive used for virtual memory

### What Hardware Features Should You Consider?
| Consideration | Questions |
|--------------|-----------|
| **Platform** | Do I need specific software? Compatible with other devices? |
| **Hardware** | Specific hardware needed? Storage requirements? |
| **Specifications** | Tasks require certain hardware specs? |
| **Form factor** | Stationary or mobile? |
| **Add-on devices** | What additional devices needed? |

- **System requirements** = minimum hardware requirements for software
- When conflicting requirements, select computer that meets or exceeds the greatest requirement
- Plan for 3-5 years of future needs

### Which Type of Computer Is Right for You?
- **Form factor** = shape and size of computer
- **Desktop** = system unit, monitor, keyboard, mouse; stationary; easily upgraded
- **All-in-one** = monitor and system unit housed together; less space; harder to service
- **Laptop** = input/output/storage/communication in one portable device
  - Traditional vs. ultrathin (lighter, less powerful, longer battery)
- **Tablet** = slate (no physical keyboard) or convertible (swivel hinge)
  - Less powerful; easy to transport; input via digital pen/stylus/fingertip

### Peripheral Devices
- **Peripheral device** = add-on device (keyboard, mouse, printer, speakers)
- **Port** = slot on computer to attach peripheral device
- **USB hub** = external device with several USB ports
- Consider extended warranty or service plan

### Mobile Computer Buyer's Guide
1. Determine form factor (tablet/ultrathin/traditional laptop)
2. Consider screen size (laptops: 11-17", tablets: 7-12")
3. Experiment with keyboards and pointing devices
4. Consider processor, memory, and storage upgrades at purchase
5. Evaluate built-in ports and slots
6. Consider battery life and second battery options
7. Purchase well-padded carrying case
8. Ensure compatibility with video projectors

### Desktop Buyer's Guide
1. Determine specific software to use
2. Know OS system requirements
3. Look for bundled software
4. Avoid least powerful desktop available
5. Consider upgrades to keyboard, mouse, monitor, etc.
6. Consider touch screen monitor
7. Evaluate all-in-ones
8. Explore purchasing options (bookstore, dealer, retail, web)
9. Be aware of additional costs (furniture, UPS, external storage)
10. Consider extended warranty for business use

## Objective 2 - Input and Output Devices

### How Computers Represent Data
- **Binary system** = number system with two digits (0 and 1)
  - 0 = absence of electronic charge; 1 = presence of electronic charge
- **Bit** = smallest unit of data (binary digit)
- **Byte** = 8 bits grouped together; represents a single character
- **ASCII** (American Standard Code for Information Interchange) = 8-bit coding scheme
- **Unicode** = 16-bit coding scheme; supports 65,000+ symbols including Chinese, Japanese, Arabic

### Input Devices
| Device | Description |
|--------|-------------|
| **Keyboard** | Keys to enter letters, numbers, symbols; wired or wireless |
| **Mouse** | Most common pointing device; wired or wireless |
| **Touchpad** | Touch-sensitive flat surface on laptops |
| **Trackball** | Stationary device with ball anchored inside casing |
| **Touchscreen** | Display that lets you touch areas to interact; multitouch for gestures |
| **Stylus** | Pen-shaped digital tool for touchscreen selections |
| **Digital pen** | Pen-shaped device with programmable buttons; can capture handwriting |
| **Microphone** | Enters voice/sound data; used for videoconferencing, voice recognition |
| **Webcam** | Digital video camera capturing video, still images, audio |
| **Scanner** | Converts paper images to electronic files; 3D scanners for objects |
| **Game controller** | Input device for video games (joysticks, gamepads, dance pads, wheels, motion-sensing) |

### Output Devices
| Device | Description |
|--------|-------------|
| **Display device** | Connected to desktops via cable; built into all-in-ones, laptops, tablets |
| **Speakers** | Convey audio output; built-in or external |
| **Headphones/Earbuds** | Personal audio output |
| **Headset** | Headphones + microphone |
| **Printer** | Creates hard copy on paper/film |
| **Projector** | Displays output on large surface (wall/screen) |
| **Voice synthesizer** | Converts text to speech; helpful for visually impaired |

### Types of Printers

## Objective 3 - Evaluate Hardware

### Performance Factors
- **Clock speed** = speed at which processor executes instructions (measured in GHz)
  - 1 GHz = 1 billion clock cycles per second
- **Bus speed and width** = determines data travel speed
  - **Word size** = bus width; 64-bit transfers faster than 32-bit
  - **Bottlenecking** = fast CPU with slow bus speed
- **Benchmark** = test to determine processor speed and performance factors
- **IPC (Instructions Per Cycle)** = efficiency measure of CPU

### Plug-and-Play vs. Device Drivers
- **Plug-and-Play devices** = function properly as soon as connected
- **Device driver** = program that allows computer to control separate device

## Objective 4 - Prevent and Troubleshoot Hardware Theft or Failure

### Avoid Hardware Theft
- **Cable lock** = inserted into security slot; connected to immovable object
- Tips: keep devices out of sight, use both hands, don't use on escalators
- If stolen: note suspect description, call authorities, contact carrier, change passwords
- **Remote wiping** = erases sensitive data on lost/stolen device

### Maintain Computer Hardware
- Turn off and disconnect from power before maintenance
- Keep media clean; avoid extreme temperatures/humidity
- Use **UPS (Uninterruptible Power Supply)** = maintains power during outages
- Use **surge suppressor** = prevents power fluctuations from damaging components
- Keep free space on device; regularly back up data
- Clean screen with damp cloth; use compressed air for keyboards
- Keep air vents free of dust

### Electrical Changes
| Change | Description |
|--------|-------------|
| **Blackout** | Total loss of power |
| **Brownout** | Drop in voltage lasting minutes/hours |
| **Spike** | Very short duration voltage increase |
| **Surge** | Short duration voltage increase |
| **Noise** | Unwanted high-frequency energy |

### Restore a Device
- Copy personal files to separate storage before restoring
- **Restoring OS** = reverting settings to default or previous version
- Check video card if display issues; update device drivers for peripherals

### Perform Data Backups
- **Data backup** = copying files stored in remote location (cloud)
- Protects against: hardware malfunctions, user error, software corruption, cyberattacks
- **Online backup services** = automatically upload changed files to cloud server
- Can schedule backups to run overnight

## Objective 5 - Internal, External, and Cloud-Based Storage

### Internal Storage
- **Hard drive** = most common storage medium
  - **HDD (Hard Disk Drive)** = magnetic storage; greater capacity, less expensive; has moving parts
  - **SSD (Solid-State Drive)** = no moving parts; faster, more durable; used in mobile devices
- Installed inside computer; not accessible from other computers

### External Storage
- **External hard drive** = housed in separate case; connects via USB cable
  - Can be transported between computers
  - Uses magnetic or solid-state technology
- **Optical media** = CDs, DVDs, Blu-ray discs (BDs); declining use
- **USB flash drive** = portable storage device

### Cloud Storage
- Storing files on remote server connected to Internet
- Access from any computer/device with Internet connection
- Companies host and maintain servers
- Advantages: access files anywhere, share via link, store large files, off-site backups

## Objective 6 - Network Hardware

### Network Connection Components
- **Node** = device on a network (computer, tablet, phone, printer, etc.)
- **Hub** = central point for cables; transfers data to ALL devices
- **Switch** = central point for cables; transfers data only to intended recipient
- **Router** = connects two or more networks; directs flow of information
  - **Wireless router** = provides wireless network access
- **Modem** = communications device connecting network to Internet via ISP

### Network Communication Devices
- **NIC (Network Interface Card)** = circuit board connecting computer to wired/wireless network
- **Cable modem** = sends/receives digital data over cable TV connection
- **DSL modem** = uses copper telephone wiring for digital data

## Objective 7 - Cases, Motherboard, System Clock, ALU, Machine Cycle, Registers

### Cases
- Made of metal or plastic; available in various shapes/sizes
- Desktop: separate from monitor; Laptop: under keyboard; Tablet/Smartphone: behind display

### Motherboard Components
- **Motherboard** = circuit board containing microprocessor, memory, other internal devices
- **Computer chip** = small piece of semiconducting material with integrated circuits
  - Contains millions/billions of elements (resistors, capacitors, transistors)
  - **Transistor** = acts as electronic switch

### Processor Cooling
- **Heat sink** = small ceramic/metal component with fins; absorbs and disperses heat
  - Many have fans to distribute air
- **Liquid cooling** = continuous flow of fluid transfers heated fluid away from processor
- **Cooling pad** = rests below laptop; protects from overheating

### The System Clock
- Small quartz crystal circuit controlling timing of all computer operations
- Generates regular electronic pulses (ticks) setting operating pace
- Each tick = **clock cycle**
- **Superscalar processor** = can execute more than one instruction per clock cycle
- Speed measured in **GHz** (gigahertz = billion cycles per second)

### The Arithmetic Logic Unit (ALU)
- Performs **arithmetic operations** (addition, subtraction, multiplication, division)
- Performs **comparison operations** (greater than, equal to, less than)

### Machine Cycle
Four basic operations repeated for every instruction:
1. **Fetching** = obtaining instruction/data from memory
2. **Decoding** = translating instruction into executable signals
3. **Executing** = carrying out the commands
4. **Storing** = writing result to memory

### Registers
- Small, high-speed storage locations in processor
- Temporarily hold data and instructions
- Part of processor (not memory or permanent storage)
- Functions: store instruction location, store data during calculation, store results

## Objective 8 - Health-Related Injuries and Disorders

### Physical Health Risks
- **RSI (Repetitive Strain Injury)** = aches/pains from repeated long-term device usage
  - Affects: elbows, forearms, hands, neck, shoulders, wrists
  - Causes: repetitive activity, improper technique, uninterrupted intensity
  - Symptoms: aching, cramp, numbness, pain, stiffness, tenderness, throbbing, tingling, weakness
- **Ergonomics** = applied science designing items for efficient/safe interaction
  - Arms: parallel to floor at ~90° angle
  - Eyes: 18-28 inches from screen; viewing angle ~20° downward
  - Feet: flat on floor; adjustable chair with 4-5 legs

### Behavioral Health Risks
- **Technology addiction** = obsessed with device; extreme anxiety when away
- **Sedentary lifestyle** = too much device time, too little physical activity
- **Psychological development** = excessive use linked to poor self-confidence, anxiety, depression
- **Social interaction** = excessive time resisting face-to-face interaction

### Social Health Risks
- **Cyberbullying** = online harassment; more harmful than traditional bullying (never ends, everyone knows, follows for lifetime)
- **Doxxing** = sharing private/personal information digitally
- **Cyberstalking** = using technology to stalk another person

## Objective 9 - E-Waste and Technology Disposal

### E-Waste
- Electronic waste from discarded digital devices
- Contains toxic metals (lead, mercury)
- Americans generate 9.4+ million tons annually
- Contains valuable materials (gold, palladium, platinum, copper)

### Responsible Disposal Methods
1. **Recycle** = take to recycling facility or designated drop-off center
2. **Donate** = give to charity, senior organization, shelter, nonprofit
3. **Trade-in** = bring to technology store for credit toward newer device

### Sustainable Electronics Management (SEM)
| Step | Action | Description |
|------|--------|-------------|
| 1 | Buy green | Purchase sustainably designed products |
| 2 | Donate | Give functional equipment to schools/charities |
| 3 | Recycle | Send to verified recycling center |

- Before disposing: back up all data, encrypt contents, reset to factory settings
- Ensure recycling facility follows health code regulations
- Verify e-waste won't be sent to developing countries
