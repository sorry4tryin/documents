	- explain how to interact with a database
		- to interact with a database, the user can first start by using the navigation pane in the selected program they are active in. the navigation pane will allow the user to see multiple objects in a database.  another way the user can interact with a database is through the internet, since each website that the user clicks on utilizes a database to provide searchable content.
			- navigation pane: a program window that lets you move between tables, queries, forms, and reports.
	- identify database components
		-  database: a collection of data organized in a way that allows you to access, retrieve and create reports of select data; contains a group of related data files.
		- data file: a table in access; a collection of related records stored on a storage medium.
		- data hierarchy: (1) table, (2) record, (3) field
			- table: a containment for records; highest level in the data hierarchy
			- record: a containment for fields
			- field: the composition of one or more characters—or bytes
				- field name: uniquely identifies each field
		- query: the process of extracting data from a database based on a specific criteria, or conditions, for one or more fields.
		- form: a user-friendly interface that allows an individual to enter data directly into a table, without having direct access to the dbms; an object that provides an easy-to-use data entry screen that generally shows only one record at a time.
		- report: a user-designed layout of database content.
		- data type: specification over the kind of data a field can contain and how the field is used.

	- discuss how to use a database system
		- a database management system is utilized to sort and filter data through a primary key (a field that uniquely identifies each record in a table—a student ID). moreover, a dbms can be used to filter (hide) specific records to the user's discretion.
