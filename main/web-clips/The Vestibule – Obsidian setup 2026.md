## notes
- don't mindlessly script notes down, because it will be a wasteful use in the workflow
	- this where you utilize your inbox to control the way you work. utilize task and embed yourself into the notes created so that they become useful
- define front-matter when it comes to notes
	- used in templates mainly
- tags are everything; especially for organizing
	- create a hierarchy of tags, for better configuration and navigation
- bullets points are everything
	- mainly due to how they create hierarchy in your notes and easily establish connections between thoughts.
		- functional when it comes to multiple thoughts in one paragraph.s
	- clean and organized
